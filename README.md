# RAIZ3Y STORE

متجر إلكتروني لشحن الألعاب، مبني ليكون آمنًا وقابلًا للتوسع.

## Stack

- Next.js + TypeScript
- Supabase
- Vercel
- Sentry
- GitHub

## Development principles

- Mobile-first workflow: المشروع يُدار من الهاتف.
- Security-first: الأسرار والصلاحيات لا توضع في الواجهة.
- Database-first: تصميم البيانات وRLS قبل الميزات الحساسة.
- AI-assisted: أدوات الذكاء الاصطناعي تتبع Skills وقواعد المشروع.

## Current status

Foundation initialized. Database, authentication, storefront, orders, admin, AI, testing, and production hardening will be implemented incrementally.
