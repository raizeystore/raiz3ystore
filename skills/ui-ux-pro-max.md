# RAIZ3Y — UI/UX Pro Max

Use this skill for every customer-facing or admin-facing interface.

## Goals
- Premium, modern, gaming-commerce visual quality without generic AI-looking layouts.
- Mobile-first responsive behavior with excellent touch ergonomics.
- Clear hierarchy, restrained effects, consistent spacing, and strong conversion UX.

## Rules
1. Define design tokens before page-specific styling: colors, typography, spacing, radii, shadows, borders, motion.
2. Do not choose brand colors or logo treatment without an approved identity direction.
3. Keep primary actions visually dominant and limit competing CTAs.
4. Forms must have labels, helper/error text, visible focus, correct autocomplete, mobile keyboard types, and predictable validation.
5. Use a consistent 4/8px spacing rhythm and a small controlled radius scale.
6. Prefer responsive grids and fluid type/spacing over breakpoint-specific hacks.
7. Build reusable primitives before duplicating UI patterns.
8. Use motion sparingly and respect prefers-reduced-motion.
9. Design for Arabic RTL first while preserving English/LTR compatibility.
10. Validate all key screens at narrow mobile, large mobile, tablet, laptop, and wide desktop widths.
