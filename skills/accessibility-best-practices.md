# RAIZ3Y — Accessibility Best Practices

Target WCAG 2.2 AA for production UI.

## Required checks
- Full keyboard navigation and logical focus order.
- Visible focus states with sufficient contrast.
- Semantic landmarks, headings, labels, buttons, links, tables, and lists.
- Form errors programmatically associated with fields; do not rely on color alone.
- Color contrast appropriate for normal text, large text, icons, and controls.
- Touch targets large enough for mobile use and spaced to avoid accidental taps.
- Meaningful alt text for informative images; decorative images ignored appropriately.
- ARIA only when native semantics are insufficient.
- Respect reduced motion and zoom/text resizing.
- RTL must not break reading order, focus order, or icon meaning.
