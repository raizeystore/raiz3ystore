# RAIZ3Y — Frontend Design

## Visual quality bar
- Avoid generic AI dashboards, random gradients, excessive glassmorphism, oversized empty hero sections, and decorative elements without purpose.
- Every page needs a clear visual concept tied to RAIZ3Y's brand and gaming-commerce context.
- Prefer deliberate composition, strong typography, controlled contrast, useful density, and polished micro-interactions.
- Components should look designed as a system, not assembled independently.

## Implementation rules
1. Start from approved wireframe and design tokens.
2. Keep UI state complete: loading, empty, error, success, disabled, hover, focus, active.
3. Use semantic HTML and progressive enhancement.
4. Keep visual effects performant; avoid expensive blur/animation on large surfaces.
5. Design mobile interactions first, then expand to larger screens.
6. Never sacrifice readability or accessibility for gaming aesthetics.
