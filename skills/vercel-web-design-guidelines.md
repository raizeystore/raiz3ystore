# RAIZ3Y — Vercel Web Design Guidelines

Use as a UI audit checklist before merging production-facing screens.

## Audit areas
- Clear page hierarchy and fast comprehension.
- Responsive layout without horizontal overflow.
- Accessible forms, dialogs, menus, navigation, and interactive states.
- Predictable feedback for async actions.
- No layout shift from images, fonts, or late UI insertion.
- Avoid blocking JavaScript and oversized client bundles.
- Keep navigation and primary actions reachable on mobile.
- Preserve SEO and semantic structure for public storefront pages.
- Make error and empty states useful rather than decorative.
- Verify performance, accessibility, and usability together rather than as separate afterthoughts.
