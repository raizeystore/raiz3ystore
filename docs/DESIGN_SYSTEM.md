# RAIZEY STORE — Design System

## Direction
Official visual direction: **Black & Orange Luxury Gaming**.

The interface must feel premium, modern, trustworthy, mobile-first, and gaming-oriented without neon overload or generic AI-template styling.

## Core colors
- `--bg`: `#080808`
- `--bg-elevated`: `#0f0f10`
- `--surface`: `#151515`
- `--surface-strong`: `#1c1c1d`
- `--border`: `#2c2c2d`
- `--text`: `#f7f7f5`
- `--text-muted`: `#a6a3a0`
- `--brand`: `#ff6a00`
- `--brand-strong`: `#ff7a1a`
- `--brand-soft`: `rgba(255,106,0,.12)`
- success: `#3fcf8e`
- warning: `#f6b73c`
- danger: `#f05b61`

## Typography
Use a readable Arabic-first system stack until the final licensed/web font is selected. Headings should be bold and compact; body copy should prioritize readability and RTL rhythm.

## Radius and spacing
- Small controls: `10px`
- Inputs/buttons: `12px`
- Cards: `18px`
- Feature surfaces: `24px`
- Minimum touch target: `44px`
- Content max width: `1180px`

## Buttons
Primary buttons use the orange brand fill with dark text. Secondary buttons use elevated dark surfaces and high-contrast borders. Focus states must remain visible and keyboard accessible.

## Forms
Inputs use dark surfaces, light text, subtle border, and a visible orange focus ring. Labels must remain visible; placeholders never replace labels.

## Cards
Cards use dark elevated surfaces, controlled borders, minimal shadows, and selective orange accenting. Avoid excessive glow, gradients, or decorative noise.

## Responsive rules
Mobile is designed independently, not as a squeezed desktop layout. Navigation, cards, typography, and CTAs must adapt intentionally below tablet widths.

## Accessibility
Follow WCAG 2.2 AA where applicable. Maintain readable contrast, visible focus, semantic forms, touch-friendly targets, and reduced-motion respect.

## Brand asset note
The current logo concept is approved as the visual reference, but the repository uses a temporary clean CSS brand lockup until a watermark-free transparent/vector production logo file is supplied.
