# RAIZEY STORE official logo source

The production brand asset for this repository is `raizey-store-logo.png`.

It is derived directly from the user-supplied official RAIZEY STORE raster artwork. Only unused outer canvas was trimmed for web layout efficiency; the R mark, RAIZEY wordmark, STORE label, colors, spacing, proportions, and orientation are unchanged.

Do not redraw, recolor, mirror, replace, or recreate this logo with CSS, text, Lucide, generated SVG paths, pseudo-elements, or another icon library.

The `BrandLogo` component is the single UI entry point for rendering the brand.
