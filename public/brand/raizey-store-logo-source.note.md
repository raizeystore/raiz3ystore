# RAIZEY STORE supplied source asset

The official source artwork was supplied by the brand owner in this task as a 2048×1365 RGBA PNG. The production web crop and compact mark are derived only by trimming unused outer canvas from that supplied artwork; the logo geometry, colors, spacing, orientation, and wording are unchanged.

The binary source is preserved in the repository as `raizey-store-logo-original.png` and the production full lockup is `raizey-store-logo.png`.
